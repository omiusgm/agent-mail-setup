# Задание агенту клиента

Скопируйте блок ниже в свой чат. Пользовательские адреса и пароли в публичный репозиторий добавлять не нужно.

> Помоги подключить мою почту по этому репозиторию. Сначала прочитай README.md и AGENTS.md. Определи ОС, клиент агента и доступные инструменты. Gmail подключай штатной интеграцией, Яндекс на Mac — через локальный read-only IMAP MCP. Проверь профиль Gmail и `connection_status` Яндекса. Пароль приложения я создам и введу в скрытом локальном запросе, в чат его не проси. Для проверки найди и прочитай одно известное письмо и проверь список вложений. Если сеть обрывается, сначала проверь TLS без входа; прямой маршрут без VPN используй после согласования со мной. В конце сообщи, какой ящик подключён, что реально проверено и какие ограничения остались.

## Порядок работы

1. Выясни, нужен ли архив Яндекса или достаточно копий новых входящих в Gmail. Не выбирай POP-сборщик по старой инструкции.
2. Проверь уже подключённые инструменты. Не переустанавливай рабочее подключение и не делай вывод о недоступности по отсутствию знакомого названия инструмента.
3. Создай отдельное Python-окружение для этого репозитория. Не устанавливай зависимости в системный Python и не переносись в соседний частный проект.
4. Выполни `probe`, настрой аккаунт локально и проверь `connection_status`.
5. Зарегистрируй только один MCP в настройках клиента; сохрани остальные записи.
6. Проверь, что инструменты появились в новом/перезапущенном сеансе, и прочитай конкретное письмо по возвращённому ID.
7. Если настроена пересылка, подтверди адрес у провайдера и проверь независимым новым письмом. Не считай её переносом архива.
8. По просьбе пользователя добавь короткую запись в личные общие инструкции агента: провайдер, адрес, способ доступа, дата проверки, ограничения. Используй шаблон из `examples/`. Реальный пароль в инструкции не включай.

## Что считать результатом

- Gmail: проверен аккаунт и прочитано известное письмо.
- Яндекс: прошёл вход, получен список папок, прочитано письмо без смены статуса; при необходимости скачано конкретное вложение.
- Пересылка: копия независимого теста реально получена в Gmail.
- Другой компьютер/облако: доступ проверен отдельно, а не унаследован на словах.

В отчёт не включай пароль, полный дамп настроек, приватные ссылки на билеты, содержимое посторонней переписки и скриншоты с секретами.
